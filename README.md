# JK BMS Monitor

Локальний desktop- та вебзастосунок для моніторингу **JK BMS** через **Bluetooth LE** у режимі **тільки читання**. Працює повністю локально без серверів і хмарних сховищ.

## Основні можливості

- **Телеметрія в реальному часі**: рівень заряду (`SOC`), залишкова ємність (`Ah`), напруга батареї, середня напруга комірок, розкид (`mV`), струм, струм балансування, потужність, температури датчиків і `MOSFET`, кількість циклів, модель і версія прошивки, статуси заряджання / розряджання / балансування.
- **Комірки та опір**: картка кожної комірки з підсвічуванням мінімуму/максимуму та внутрішнім опором (`mΩ`, безпосередньо з телеметрії JK02).
- **Графік напруги комірок**: три режими — *Огляд* (діапазон min–max і середнє), *Теплова карта* та *Окрема комірка* (відкривається також кліком по картці комірки). Діапазон 1–30 хв з агрегацією щільних даних зі збереженням піків.
- **Прогноз розряду та заряду**:
  - Оцінка часу до повного розряду або повного заряду на основі неперервної поточної сесії (після 30 с — середній струм за останні до 5 хв, до того — поточний струм; перерви чи зміна режиму не спотворюють розрахунок).
  - Для прогнозу заряду використовується номінальна ємність із кадру BMS (`nominalCapacity`), що дозволяє працювати навіть при `0% SOC` (із резервним розрахунком через залишок і `SOC`, якщо номінальна ємність відсутня).
- **Періоди заряду та розряду**: групування активності за напрямком струму (мертва зона `±0,1 A`, об’єднання пауз до 5 хв), розрахунок активного часу, енергії (`kWh`), середньої напруги, зміни `SOC` та діапазону струму; графік + таблиця з пагінацією. Позначка `≈` вказує на незафіксовану межу початку/кінця періоду.
- **Тривоги та захист**: декодування відомих бітів помилок `JK02_24S` / `JK02_32S` із показом нерозпізнаних бітів як hex-коду.
- **Гнучке компонування дашборда**: перетягування блоків за маркер `⠿`, зміна ширини й висоти кутовим маркером `⤡` або стрілками клавіатури; порядок і розміри зберігаються локально.
- **Локальний журнал і CSV-експорт**: окреме збереження історії для кожної BMS у `localStorage` (до 2 000 вимірювань та до 10 000 точок історії струму з автоматичним видаленням найстаріших блоків) і ручний експорт у CSV (UTF-8 BOM, коректні від’ємні числа та захист текстових комірок від формульних ін’єкцій).
- **Зручний інтерфейс**: компактна верхня панель із кнопками-іконками та підказками (tooltip), усі статуси, помилки, підказки й оновлення показуються у єдиній системі тост-повідомлень.

## Встановлення готового застосунку

Завантаж інсталятор для своєї ОС зі сторінки [GitHub Releases](https://github.com/vcpstudio/jkbms/releases/latest):

### macOS (`.dmg`)

1. Відкрий завантажений `.dmg` і перетягни **JK BMS Monitor** у папку **Програми** (`/Applications`).
2. Оскільки релізна збірка macOS наразі **не підписана сертифікатом Apple Developer ID і не нотаризована**, при першому запуску завантаженого з браузера файлу macOS Gatekeeper (особливо на Apple Silicon) покаже повідомлення:
   > *«Програму «JK BMS Monitor» пошкоджено, її не можна відкрити. Потрібно перенести її у Смітник.»*

   Програма не пошкоджена — це стандартне блокування атрибута карантину (`com.apple.quarantine`). Щоб зняти карантин, виконай у Терміналі один раз:

   ```sh
   xattr -cr "/Applications/JK BMS Monitor.app"
   ```

   Після цього застосунок відкриватиметься у звичайному режимі.
3. При першому підключенні надай системний дозвіл на використання Bluetooth.

### Windows (`.exe`)

Запусти NSIS-інсталятор `.exe`. Якщо спрацює Windows SmartScreen для непідписаного застосунку, натисни **Докладніше → Все одно виконати**.

### Linux (`.AppImage`)

Надай файлу права на виконання та запусти його:

```sh
chmod +x JK-BMS-Monitor-*.AppImage
./JK-BMS-Monitor-*.AppImage
```

## Керування (верхня панель)

- `⌁` — **Підключити BMS** (відкриває вікно вибору Bluetooth-пристроїв із пошуком, «Останніми підключеннями» та «Обраним»).
- `⏻` — **Від’єднати BMS**.
- `↻` — **Оновити дані** (повторно надсилає запити читання `0x96` / `0x97`).
- `⇧` — **Перевірити оновлення** (лише в установленій desktop-версії).
- `▦` / `✓` — **Компонування блоків** (увімкнути / завершити редагування сітки).
- `↺` — **Скинути компонування** (доступна в режимі редагування).

## Оновлення desktop-застосунку

Desktop-застосунок автоматично перевіряє нові релізи на GitHub після запуску й показує статус у тост-повідомленнях:

- **Windows і Linux**: можна завантажити оновлення та перезапустити застосунок безпосередньо з тоста.
- **macOS**: через відсутність підпису й нотаризації застосунок повідомляє про нову версію та відкриває сторінку релізу для ручного встановлення нового `.dmg`.

## Запуск у браузері

Статичну вебверсію можна запустити без Electron у **Chrome** або **Edge** (потрібен Web Bluetooth API та безпечний контекст `localhost` або `HTTPS`; Safari та Firefox не підтримують Web Bluetooth):

```sh
python3 -m http.server 8000
```

Після цього відкрий <http://localhost:8000>.

## Розробка та збірка

Потрібен **Node.js 22.12** або новіший.

```sh
npm install
npm start
```

Застосунок відкриється в окремому вікні Electron, завантажуючи локальні файли через внутрішню схему `jkbms://app`. Окремий вебсервер не потрібен.

### Збірка інсталяторів локально

```sh
npm run dist:mac    # macOS (.dmg) — на macOS відкривається без карантину Gatekeeper
npm run dist:win    # Windows (.exe, NSIS)
npm run dist:linux  # Linux (.AppImage)
```

Готові файли з’являються в каталозі `release/`.

### Тести

```sh
npm test
```

Запускає всі модульні тести (`node --test`):
- `protocol.test.mjs` — збирання кадрів, контрольні суми, `JK02_24S` / `JK02_32S`, номінальна ємність, захисти та ігнорування нульових комірок.
- `discharge-forecast.test.mjs` — прогнози розряду й заряду, зміна режиму, `0% SOC`.
- `flow-periods.test.mjs` — об’єднання/розбиття періодів, паузи, межі сесій та відключень.
- `voltage-chart-data.test.mjs` — агрегація графіка напруг зі збереженням піків.
- `app-utils.test.mjs` — форматування CSV, фільтрація й обмеження історії струму, відновлення пошкоджених чанків, пошук останніх Bluetooth-пристроїв.

### Публікація релізу

Реліз у GitHub запускається автоматично при пуші тегу `v*` через [.github/workflows/release.yml](.github/workflows/release.yml):

1. Онови версію в `package.json` і `package-lock.json` та закоміть зміни.
2. Створи **анотований** тег з описом змін (його текст автоматично стане описом GitHub Release):
   ```sh
   git tag -a v1.1.0 -m "Опис змін..."
   git push origin main v1.1.0
   ```
3. GitHub Actions прожене `npm test`, збере інсталятори для macOS, Windows і Linux та створить GitHub Release.

*(Для повноцінного розповсюдження macOS-збірки без повідомлення Gatekeeper і з автооновленням потрібні підписання сертифікатом Apple Developer ID та нотаризація Apple.)*

## Сумісність протоколу та безпека

- **Протокол**: класичний **JK02 BLE** — сервіс `FFE0`, характеристика `FFE1`, команди читання `0x96` (інформація про пристрій) та `0x97` (налаштування й телеметрія), кадри довжиною 300 байтів.
- **Профілі `JK02_24S` та `JK02_32S`**: визначаються автоматично за моделлю й апаратною версією окремо від фактичної кількості комірок (наприклад, `JK_B1A8S20P` із 8 комірками використовує `JK02_32S`). Старий протокол `JK04` не підтримується.
- **Тільки читання**: запис налаштувань у BMS навмисно відсутній — застосунок ніколи не змінює конфігурацію батареї.
- **Ізоляція Electron**: увімкнені `contextIsolation`, `sandbox`, вимкнений `nodeIntegration`, суворий CSP, білий список дозволених файлів рендерера для `jkbms://app` та блокування сторонніх переходів і нових вікон.
- **Приватність**: жодні дані телеметрії не відправляються на зовнішні сервери.

Перед використанням у критичних системах перевір сумісність кадрів зі своєю моделлю BMS. Публічні специфікації протоколу: [ESPHome JK-BMS BLE protocol notes](https://github.com/syssi/esphome-jk-bms/blob/main/docs/protocol-design-ble.md) та [Better BMS App](https://github.com/encap/better-bms-app).

## Структура проєкту

- `index.html`, `styles.css`, `app.mjs` — інтерфейс дашборда, BLE-підключення, графіки, тости, компонування та локальне збереження.
- `protocol.mjs` — парсер кадрів JK02 BLE (`0x01`, `0x02`, `0x03`), контрольні суми й прапорці захисту.
- `discharge-forecast.mjs` — розрахунок прогнозу часу розряду та заряду.
- `flow-periods.mjs` — побудова періодів заряджання/розряджання та інтегрування енергії.
- `voltage-chart-data.mjs` — часова агрегація напруг комірок для графіка й теплової карти.
- `app-utils.mjs` — чисті допоміжні утиліти (CSV, лімітування/парсинг чанків історії, матчинг останніх пристроїв).
- `electron/` — головний процес Electron (`main.cjs`), preload-скрипти (`preload.cjs`, `bluetooth-picker-preload.cjs`) і вікно вибору Bluetooth-пристроїв (`bluetooth-picker.*`).
